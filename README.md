# PDFly

A privacy-focused PDF toolkit built as a personal full-stack learning project.

## MVP Features
- Merge PDF
- Split PDF
- Images to PDF
- Rotate PDF

## Tech Stack
- HTML
- CSS
- JavaScript
- pdf-lib

## Goal
Build a functional PDF toolkit while learning frontend and full-stack development.

## Privacy
The goal is to process files locally in the browser without uploading or storing documents on a server.
